سیستەمێ دوکانێ - پێشکێشکرنا دوماهیێ (PWA، ب ئۆفلاین کار دکەت)
================================================================

فایل (هەر ٥ ل ڕووی ڕێپۆزەتۆرییێ بن، ناڤێن وان نەگۆڕە):
  index.html   سیستەم
  manifest.json
  sw.js        ئەو کو سیستەمی ب ئۆفلاین کار دکەت
  icon-192.png / icon-512.png

چەوا نوی بکەی ل GitHub:
  ١. ل تابا "داتا" Backup بگرە (بەری هەر تشتەکی).
  ٢. ل ڕێپۆزەتۆرییێ: Add file ← Upload files ← index.html و sw.js (ئەگەر ئەو یێن دی هەنە، ناگۆڕدرێن).
  ٣. Commit changes.
  ٤. ئەپی ب ئینتەرنێت ڤەکە، ٥ چرکەیان ڕاوەستە، دابخە، و دووبارە ڤەکە.

بەشێن سیستەمی:
  فرۆتن (سکان، داشکاندن ب سنوور، پارەدان ب د.ع/$/€/₺ و باقی ب دینار، ب قەرز، هەلگرتنا فاتورێ)
  زڤڕاندن و بەدەلکرن (ژ ناڤ فاتورێ دچیت و ژ حسابێ دهێتە کێمکرن)
  بەرهەم (بهایێ کڕینێ و قازانج) و ستۆک (باتچ و دەمێ بەسەرچوونێ)
  کڕیار (لیستا قەرزداران و سنوورێ قەرزی بۆ هەر کەسەکێ)
  تاجر (کڕین ژ تاجران، قەرزێ تە ل وان، پارەدان)
  بارکۆد (چاپکرنا لیبلان ب Code128، ٥ قەبارە: ٤٠×٢٥، ٥٠×٣٠، ٦٠×٤٠ مم و A4 ٣×٨ و ٤×١٠)
  سندوق (خەرجی، زێدەکرن/دەرئینانا پارە، داخستنا ڕۆژێ ب ژمارتنا کوێرانە)
  ڕاپۆرت (ڕۆژانە هەتا سالانە، قازانجا پاک پشتی خەرجیان، فرۆتن ب کاشێر)
  ئەندام (PIN، ڕێپێدانێن کاشێری، کۆدا ڤەگەڕاندنێ، تۆمارا کاران)
  داتا (Backup، Excel، ڤەگەڕاندن، 📦 ئارشیڤ، ☁️ سینکا Firebase، دامەزراندن وەک ئەپ)

ئامۆژگاریێن گرنگ:
  - هەر ڕۆژەکێ پشتی داخستنا دوکانێ Backup بگرە.
  - PINێ خۆ ب کەسی نەدە، و کۆدا ڤەگەڕاندنێ ل جهەکێ ئێمن بنڤیسە (نە ل ڤی ئامیری).
  - داتا ل هەر ئامیرەکێ و هەر وێبگەڕەکێ جودایە. ئەگەر لینک یان دۆمەین بگۆڕی، داتا نامینیت.
  - پشتڕاستکرن (ژێبرن، داخستن، ڤەگەڕاندن) ل ناڤ لاپەڕێ دهێن، نە ب پنجەرێن وێبگەڕێ.
  - ئاسایشا PIN و ڕێپێدانان ئاسایشا دوکانێیە (ل ناڤ ئامیری)، نە ئاسایشا بانکی.

سنوورێن ناسیار:
  - سینکا Firebase ب ڤێرژنانە و یەک نڤیسەر د ئێک دەمی دا یە (ل خوارێ). دوو کاشێر د هەمان دەمی دا فرۆتن بکەن ناکۆکیێ دروست دکەت.
  - چاپکرنا لیبلان ب چاپکەرێ ڕاستەقینە هێشتا ل سەر کاغەزی نەهاتیە تێستکرن (دڤێت تو بکەی).
  - ستۆک ل فاتورا هەلگرتی ناهێتە ڕاگرتن.
  - زڤڕاندنا کالا بۆ تاجری هێشتا نینە (تنێ هەلوەشاندنا کڕینێ).

سینکا ل نافبەرا ئامیران (Firebase) - هەنگاڤ ب هەنگاڤ:
  ١. console.firebase.google.com ← پرۆژەیەکێ چێبکە (یان یا هەی بکاربینە).
  ٢. Build ← Authentication ← Get started ← Sign-in method ← Email/Password ← Enable.
     پاشی Users ← Add user: ئیمەیلەک و پاسۆردەکێ بنڤیسە (ئەڤە بۆ هەمی ئامیران).
  ٣. Build ← Firestore Database ← Create database ← پاشی تابا Rules ← ڕێسایێ بچەسپینە (ل ناڤ ئەپی ل تابا "داتا" ← ☁️ دیار دبیت) ← Publish.
  ٤. Project settings (⚙️) ← Your apps ← </> (Web) ← Register ← firebaseConfig کۆپی بکە.
  ٥. ل ئەپی: تابا "داتا" ← ☁️ سینک: firebaseConfig + ئیمەیل + پاسۆردێ بچەسپینە ← "پەیوەندیێ بکە".
  ٦. هەمان کار ل هەر ئامیرەکێ دی بکە (هەمان ئیمەیل و پاسۆرد). ئامیرێ نوی ب خۆکار داتا دابەزینیت.

چەوا کار دکەت:
  - هەر گۆڕانکاری ب ڤێرژنەک ل Firebase دهێتە پاراستن (ڤێرژن #١، #٢...).
  - ئامیرێ گۆڕانکاری نەکری، ب خۆکار داتایا نوی دابەزینیت (هەر ٢٠ چرکەیان).
  - ئەگەر دوو ئامیر د هەمان دەمی دا گۆڕانکاری کر، سیستەم هیچ تشتەک ب بێ دەنگی نانڤیسیت. ناکۆکی دیار دبیت و تو دەستنیشان دکەی کا داتایا کیژان ئامیری بمینیت. کۆپییەکا ئێمن ل ئامیرێ ڤەگەڕاندی دمینیت.
  - ئامیرێن تنێ بۆ دیتنێ (مثلا مۆبایلا خودانی): "تنێ خواندن" هەلبژێرە.
  - ئەگەر ئینتەرنێت نەبیت، ئەپ ب ئۆفلاین کار دکەت و پشتی ئینتەرنێت هاتی سینک دبیت.
  - ئەڤە ئەو دانەیە کو دەمێ دوو کاشێر ل دوو ئامیران د ئێک دەمی دا فرۆتن بکەن، ناکۆکیێ دروست دکەت. بۆ ڤێ، ڕێکا باشتر: یەک ئامیر بۆ فرۆتنێ، و ئامیرێن دی بۆ دیتنا ڕاپۆرتان.

ستۆرکرن و ئارشیڤ (نوی):
  - داتا نوکە ل IndexedDB دهێتە پاراستن (نە تنێ localStorage)، ژ بەر هندێ سنوورێ ٥ MB نەما. نموونە: ٢٢ هزار فرۆتن (٦ MB) هاتە پشکنین.
  - داتایێن کۆن ب خۆکار دهێنە خواندن (ژ localStorage بۆ IndexedDB) ب بێ ژ دەست چوون.
  - 📦 ئارشیڤ (تابا داتا): فرۆتنێن ژ ٣/٦/١٢ هەیڤان کۆنتر دچنە ئارشیڤێ دا سیستەم خێرا بمینیت. د Backup دا دهێن و دشێی بزڤڕینی (↩).
    ئارشیڤ ل ناڤ ئامیری دمینیت (ل ئامیرێن دی نابیتە سینک).
  - سینک: گوهدارییەکا زیندی هەیە، ئامیرێن دی داتایا نوی د ١ تا ٣ چرکەیان دا وەردگرن (ئەگەر ئینتەرنێت هەبیت).
